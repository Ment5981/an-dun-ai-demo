# 案盾 AI 演示版

根据《案盾 AI PRD V3.0 MVP 落地版》实现的可运行交互 Demo，聚焦运输纠纷案件闭环。

## 运行

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`。

生产构建：

```bash
pnpm build
pnpm preview
```

## 推荐演示路径

1. 点击右上角“演示脚本”快速查看讲解顺序。
2. 进入“AI 智能报案”，使用默认相机货损描述开始分析。
3. 依次确认下单关系和发现时点。
4. 提交“监控明天会覆盖”，观察紧急中断和 P0 行动生成。
5. 创建案件，查看概览、事实、证据、风险、行动、时间线和 AI 助手。
6. 点击“标记已固定”，观察案件阶段和证据状态更新。
7. 切换到行动中心和管理驾驶舱查看全局视角。

“自动演示”可以跳过手动追问，在约 5 秒内直接演示到紧急证据识别结果。

## 技术栈

- React 19 + TypeScript + Vite
- Fluent UI 9 企业级组件体系
- Motion 页面与状态过渡
- Playwright 自动化演示链路和响应式视觉验收

所有比赛用指标和非生产案件数据均以 `Demo Data` 或 `Pilot Target` 标注。
