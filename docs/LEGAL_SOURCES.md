2025年修订后的《快递暂行条例》中，快件损失赔偿条款为**第二十八条**，投诉处理为**第二十九条**。旧版条文编号不可直接沿用。知识条目保存来源链接、版本、核对日期、类型与演示标识；界面引用使用服务器实际检索命中的条目和释义摘录，不让模型生成来源。

本项目的两个内部 SOP、一个历史案例、文书模板均由项目为比赛编写，标题及正文明确标为“演示”或“模拟”。它们并非顺丰真实内部制度、企业授权标准、真实诉讼案例或法务已审核模板，没有虚构案号、裁判结果或胜诉率。

## 取证与期限

- “立即固定 / 待补充 / 已具备”依据取证类别和实际文件记录生成。文件名、案情中提及“有监控”等不能代替上传文件。已具备仅表示该类别已有文件，仍需人工审查内容。
- SHA-256 是服务器接收文件后的完整性校验值，不证明文件形成时间、真实性或法律证明力，不等同于公证、可信时间戳或司法存证。
- 监控的实际覆盖时间由使用者从设备管理人处确认并录入。两小时固证提醒为演示作业建议，不能解释为监控统一留存期或法律期限。
- 法院举证、保险报案期限应依据法院通知、具体保单等来源逐项登记；系统不自动编造法定举证天数。保价不等于保险，不能仅根据“已保价”自动认定已投保。
- 《快递暂行条例》第二十九条的七日针对收到服务质量投诉后的处理并告知，不是统一赔付完成期、保险期或法院举证期。[对应官方文本](https://www.mee.gov.cn/zcwj/gwywj/202504/t20250422_1117316.shtml)

## 本地检索与可选模型

`server/ai.mjs` 的 `retrieveKnowledge` 实施中文二元词组与关键词加权的稀疏检索。它按实际匹配排序，仅返回正分条目和来源摘录；未命中时不虚构引用。本 MVP 使用小规模可审计语料，无需向量数据库。

不配置密钥时，采用本地检索 + 案型、证据缺口、风险升级规则，分析结果明确返回 `mode: "rules"` 和回退说明。可以通过服务器环境变量配置兼容 Chat Completions 的模型：`AI_API_KEY`、`AI_BASE_URL`（默认为 `https://api.openai.com/v1`）、`AI_MODEL`（默认为 `gpt-4o-mini`）。密钥不发送至浏览器。

配置模型后，服务器将结构化事实、证据缺口和检索片段提供给模型，由模型在受控候选中选择、排序争议焦点、澄清问题及摘要，返回 `mode: "llm"`。文件原始内容、运单号、姓名、地址、联系方式和案情原文不发送给模型；MVP 不进行 OCR、视频理解或文件正文事实提取。模型返回值只能使用服务器提供的候选 ID 和引用 ID，无法添加法条、案号、比例、胜诉率或证据事实。超时、错误或来源校验失败时自动退回本地检索和规则，保留可见提示。

风险、证据状态、处置期限与升级条件始终由服务器规则计算，模型不能降低它们。主张金额达到 ¥10,000、标记重大案件或发现待核实刑事线索时自动分流人工法务。该金额仅为比赛示例配置，既不代表法律标准，也不代表顺丰赔偿审批权限。
